# Let's Practice — стандарт рабочих листов

[Read in English](STANDARDS.md) · Причины и исследования: [DESIGN.ru.md](DESIGN.ru.md)

**Цель: каждый ребёнок справляется, и успех вызывает желание делать больше и сложнее.**
Каждое задание, страница и карточка должны соответствовать этому стандарту. В pull request ссылаются на номера правил
(например, «исправляет D2»).

Размеры указаны в px страницы A4 (794 × 1123 px, печать 96 dpi): **1 pt = 1,33 px**.

## Откуда цифры

| Источник | Что задаёт | |
|---|---|---|
| **Украина** — письма МОН 2022 и 2018 для 1 класса | буквар 20 pt; другие предметы, в т. ч. математика, 17 pt рубленым шрифтом; дополнительный текст 15 pt; интерлиньяж +2 pt; не больше 3 цветов в выделениях; минимум декора; чёткие различимые условные знаки; реалистичные контурные рисунки | [2022][ua22], [2018][ua18] |
| **Россия** — СанПиН для учебных изданий | 1–4 классы: 12–18 pt; текст длиннее 200 знаков на сером/цветном фоне на 2 pt крупнее; узкие шрифты запрещены; не больше 4 вариантов шрифта | [только вторичный пересказ][ru], первоисточник ещё не сверен |
| **Европа** — Inclusion Europe «Information for all» | шрифт без засечек от 14 pt; без курсива; без слов заглавными; без фона-картинки; мало текста на странице; выравнивание влево; номера страниц; картинки рядом с текстом, в одном стиле; числа цифрами; короткие позитивные фразы | [стандарт][ie] |
| **Великобритания** — British Dyslexia Association (через Dyslexia Scotland) | шрифт без засечек 12–14 pt и больше; светлый, не белый фон; без курсива | [руководство][bda] |
| **Доступность** — WCAG 2.1 | цвет не единственная подсказка; контраст | [1.4.1][wcag] |
| **Исследования** | украшения отвлекают (сильнее при аутизме); решённые примеры; наглядные опоры; около 80 % успеха; хвалить усилия; самоконтроль | см. [DESIGN.ru.md](DESIGN.ru.md) |

Где источники расходятся, берём **самое строгое**: например, 17 pt (Украина) для текста, который читает ребёнок, а не 12–14 pt.

## T — Текст

| № | Правило | Источник |
|---|---|---|
| T1 | Шрифт Nunito (округлый, без засечек); греческий — M PLUS Rounded 1c. Без засечек, без узких шрифтов, **без курсива**. | UA, RU, IE, BDA |
| T2 | Текст, который **читает ребёнок** (слова, предложения, подписи в задании): **не меньше 23 px (17 pt)** в Reception и Year 1, не меньше 20 px (15 pt) с Year 2. | UA 2022 |
| T3 | Числа, которые ребёнок читает или пишет: не меньше 24 px; окошки для ответа не меньше 44 px, чтобы поместился детский почерк. | UA 2022, практика |
| T4 | Текст **для взрослого** (инструкция рядом со значком, страница ответов, подсказки): не меньше 16 px (12 pt), тёмно-серый или чёрный. | BDA |
| T5 | Межстрочный интервал не меньше 1,35 (≈ +2 pt). | UA 2022 |
| T6 | Выравнивание влево; без переносов; слово никогда не разрывается между строками. | IE |
| T7 | Никаких слов ЗАГЛАВНЫМИ буквами (кроме цифр и знаков). | IE |
| T8 | Никакого сплошного текста длиннее 200 знаков на сером фоне. | RU (вторичный) |
| T9 | Числа цифрами (кроме задания «числа словами»). | IE |

## L — Страница

| № | Правило | Источник |
|---|---|---|
| L1 | A4 книжная, поля 40 px, чёрно-белая. Помещается на A4 на **любом** языке (`check_layout.py`). | практика |
| L2 | Одно задание — одна рамка: номер в чёрном кружке → значок действия → короткая инструкция. | UA 2018 (единые знаки) |
| L3 | Не больше **2 заданий на странице** в Reception, **3** в Year 1, **4** с Year 2. | IE, CHADD, практика |
| L4 | Пунктов в задании: 3–6 в Reception, 3–8 в Year 1. | практика |
| L5 | Номер страницы на каждой странице: «1 / 4», внизу справа. | IE |
| L6 | Последнее задание на странице может растягиваться, но держится под своим заголовком (свободное место сверху и снизу). | практика |
| L7 | Лист — это 15–20 минут работы и не больше 4 страниц (+ ответы). | практика |

## G — Графика и цвет

| № | Правило | Источник |
|---|---|---|
| G1 | Чёрное на белом. Серый только для: решённого примера, точек для обведения, раскрашенного образца в задании на раскрашивание. Цвет никогда не несёт смысла. | UA (≤ 3 цветов), WCAG, исследования |
| G2 | **Никаких украшений.** Картинка появляется, только если она нужна для задания (посчитать, сравнить, соединить…). Никаких фоновых картинок и узоров. | IE, UA 2018, Fisher, Hanley |
| G3 | Простые контурные рисунки в одном стиле; настоящие узнаваемые предметы с их главными деталями; одна и та же вещь всегда нарисована одинаково. | UA 2018, IE |
| G4 | Картинки достаточно крупные, чтобы считать без усилия: не меньше 22 px на предмет, предметы не касаются друг друга. | практика |
| G5 | Совет для дислексии: печатать на кремовой или пастельной бумаге (сам лист остаётся белым, чтобы экономить краску). | BDA |

## I — Значки

| № | Правило | Источник |
|---|---|---|
| I1 | У каждого задания на каждом этапе ровно один **значок действия** из постоянного набора: посчитай, обведи, соедини, раскрась, обведи по точкам, напиши, отметь, зачеркни, нарисуй. | NCAEP (наглядные опоры), UA 2018 |
| I2 | Один значок = одно действие, везде. Новое действие — новый значок, сначала обсуждаем в issue. | UA 2018 |
| I3 | Инструкция для взрослого рядом со значком называет то же действие. | IE |

## D — Сложность, успех и мотивация

| № | Правило | Источник |
|---|---|---|
| D1 | **Первый пункт каждого задания уже решён**, на сером («делай так же»). Ровно один пример. | решённые примеры, Розеншайн |
| D2 | Пункты идут **от лёгкого к сложному** внутри задания (после примера — самый лёгкий). | Розеншайн (маленькие шаги) |
| D3 | Цель — около **80 % успеха**: все пункты в пределах этапа; ничего из следующей четверти без метки. | Розеншайн |
| D4 | Необязательный **пункт-вызов ★** в конце задания, явно отмеченный; пропустить его — никогда не «ошибка». | теория самодетерминации (оптимальный вызов) |
| D5 | У каждого задания **ровно один правильный ответ**, он есть на странице ответов с меткой программы. | практика |
| D6 | **Квадратик «Сделал»** у заголовка каждого задания, ребёнок отмечает сам; карточки-шпаргалки заканчиваются «Я умею!». | самоконтроль (Gaastra 2016) |
| D7 | Слова хвалят **усилия и способ**, а не способности: «я потренировался», «я проверил», никогда «ты умный». | Mueller & Dweck 1998 |
| D8 | Путь вперёд виден: страница ответов и сайт предлагают «**дальше — чуть сложнее**» (следующий уровень или четверть). | самодетерминация (компетентность) |
| D9 | Выбирает ребёнок или родитель (темы, порядок заданий); лист никогда не наказывает за пропуск. | самодетерминация (автономия) |

## W — Формулировки

| № | Правило | Источник |
|---|---|---|
| W1 | Инструкции: повелительное наклонение, не больше 8 слов в предложении, не больше 2 предложений, позитивно («Обведи…», а не «Не…»). | IE |
| W2 | Одно действие — одни и те же слова во всех заданиях и языках. | IE |
| W3 | Все тексты — в `scripts/i18n.py`; у каждого языка все тексты; носители языка проверяют их. | проект |

## A — Сайт и доступность

| № | Правило | Источник |
|---|---|---|
| A1 | WCAG 2.1 AA: контраст не меньше 4,5 : 1, работа с клавиатуры, видимый фокус, язык страницы, никаких подсказок только цветом. | WCAG |
| A2 | Кнопки и цели касания не меньше 44 × 44 px. | WCAG 2.5.5 (AAA, практика) |
| A3 | Вариант не белого фона для просмотра на экране. | BDA |
| A4 | Никаких аккаунтов, оплаты, рекламы, слежки и сбора данных. | принципы проекта |

## C — Карточки-шпаргалки

| № | Правило |
|---|---|
| C1 | Одна карточка на тип задания, пол-листа A4, всегда: Смотри → Делай (≤ 3 шагов) → Проверь → Попробуй → «Я умею!». |
| C2 | Числа другие, чем на листе, чтобы карточка не выдавала ответы. |
| C3 | Решённый пример в «Смотри» читается слева направо в одну строку. |

## Чек-лист для нового задания

- [ ] значок действия (I1) и решённый первый пункт на сером (D1)
- [ ] пункты от лёгкого к сложному (D2), в пределах этапа (D3)
- [ ] текст для ребёнка ≥ 23 px (T2), для взрослого ≥ 16 px (T4), без заглавных и курсива (T1, T7)
- [ ] картинки только если нужны, в одном стиле, ≥ 22 px (G2–G4)
- [ ] один правильный ответ на странице ответов с меткой программы (D5)
- [ ] все тексты в `i18n.py` (W3); инструкция ≤ 8 слов в предложении (W1)
- [ ] проходят `python scripts/measure_topics.py` и `python scripts/check_layout.py` (L1)
